# Diagrams

The course requires PlantUML for every UML diagram. Each diagram lives here as a
`.puml` source with a PNG export next to it for the slides.

**To render:** paste the file into https://www.plantuml.com/plantuml and download
the PNG, or install the VS Code "PlantUML" extension and press Alt+D to preview.
Commit both the `.puml` and the `.png`.
