# Diagrams

The course requires PlantUML for every UML diagram. Each diagram lives here as a
`.puml` source with a PNG export next to it for the slides.

**To render:** paste the file into https://www.plantuml.com/plantuml and download
the PNG, or install the VS Code "PlantUML" extension and press Alt+D to preview.
Commit both the `.puml` and the `.png`.

| Diagram | Source | PNG | Notes |
|---|---|---|---|
| Use case | `use-case.puml` | `use-case.png` | Includes Give up and Resume round |
| Sequence: register → verify → login | `sequence-register-verify.puml` | `sequence-register-verify.png` | Matches `apps/api` messages, status codes and token expiry |
| Sequence: forgot → reset password | `sequence-password-reset.puml` | `sequence-password-reset.png` | Matches `routes/auth.ts` (1-hour token, always-200 forgot) |
| ERD | `erd.puml` | `ERD.png` | Matches `apps/api/src/models`; `games.guesses` is embedded |
| Activity: one game round | `activity-game-round.puml` | `activity-game-round.png` | Web game round, incl. resume, Give up, Play again |
| Class diagram (mobile) | `class-mobile.puml` | `class-mobile.png` | Matches `apps/mobile/lib`, incl. `giveUp()`, distance/direction and the globe |

The Gantt chart isn't UML. It's generated by `docs/pm/gantt.mjs` (see
[docs/pm/gantt.md](../pm/gantt.md)).
